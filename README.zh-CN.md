Glide Translate（轻译）是一款开源、重视隐私的 macOS 菜单栏翻译工具，支持划词翻译和手动输入。它运行在 macOS 14 及更高版本上，默认使用本机 Ollama 模型，也支持用户自行配置的 OpenAI 兼容服务。

本文档对应 **v0.2.2**。

轻译默认使用本机 Ollama。也可以输入 API 地址和密钥，获取 OpenAI 兼容服务提供的模型列表，再选择要使用的模型。

> [!IMPORTANT]
> 当前可下载的 `v0.2.2` 是 Apple 芯片 Mac 的预发布版本。应用使用 ad hoc 签名检查包体完整性，但没有 Developer ID 签名，也没有经过 Apple 公证。首次打开前请先阅读[安装预发布版本](#安装预发布版本)。

## v0.2.2 使用体验

v0.2.2 重点改善模型配置、划词翻译稳定性和 macOS 界面布局：

- **模型配置流程更直接。** 添加 Ollama 或 OpenAI 兼容提供方，输入 API 地址和凭据，获取模型列表，再启用需要的模型。手动翻译和划词翻译会稳定使用当前选择的提供方。
- **长译文可以稳定阅读。** 只有停留在底部附近时，流式结果才会跟随最新内容；向上滚动或拖动滚动条后，不会再被强制拉回底部。
- **临时翻译框可靠关闭。** 通过方向键、编辑或删除取消选区时，未固定的结果框会关闭，固定结果仍会保留。
- **设置和历史记录更清晰。** 设置页使用带品牌元素的紧凑侧栏和自适应双栏布局；历史记录按日期分组，并保持合理的列表与详情比例。
- **提示词预览更完整。** 预设会显示发送给模型的完整内容，包括规范的 `{text}` 占位符和模板格式说明。
- **中英文布局保持稳定。** 在英文和简体中文之间切换时，标签会立即更新，设置窗口不会重建或错位。

## 主要特点

- **翻译所选文本。** 在其他应用中选中文字，按下 `⌥⇧D`，就能在选区旁边看到译文。
- **无需辅助功能权限的手动输入。** 按下快捷键但没有可用选区时，应用会打开手动翻译窗口。手动输入不会读取剪贴板。
- **本地模型与自选服务。** 支持 Ollama 原生接口和 OpenAI 兼容接口。一次请求始终绑定到所选服务，不会在失败后悄悄切换到其他提供商。
- **按需启用的自动捕获。** 鼠标和键盘选区捕获默认关闭；只有加入允许列表的应用才能启用。
- **实用提示词。** 内置准确翻译、自然翻译、解释单词、解释句子和润色五种预设，也可以复制预设或创建加密保存的自定义预设。
- **可控的本地历史记录。** 历史记录默认关闭。启用后，已完成翻译的原文和结果会加密保存，可在本机搜索，并受保留天数和数量上限约束。
- **中英文界面。** 可以在设置中切换简体中文或英文，不需要修改系统语言。

## 一次翻译如何完成

```text
所选文本或手动输入
        ↓
检查触发方式、来源应用，以及文字将发送到哪里
        ↓
发送给已选择的 Ollama 或 OpenAI 兼容服务
        ↓
流式结果面板 → 复制、重试、更换预设或固定
```

自动捕获只有在用户主动开启、允许来源应用，并启用鼠标或键盘捕获后才会工作。如果翻译服务不在本机，还要允许该应用使用这个服务。

## 安装预发布版本

[v0.2.2 预发布版本](https://github.com/ZacharyJiao/GlideTranslate/releases/tag/v0.2.2)提供一个适用于 macOS 14 及更高版本的 Apple 芯片 DMG。

1. 从发布页面下载 `GlideTranslate-0.2.2-macos-arm64.dmg`。
2. 打开 DMG，将 `GlideTranslate.app` 拖到“应用程序”文件夹。
3. 在 Finder 中推出 DMG。
4. 在“应用程序”中先尝试打开一次。由于这是未识别且未公证的预发布版本，macOS 可能会拦截它。
5. 如果 macOS 拦截，请打开“系统设置 → 隐私与安全性”，在“安全性”区域找到轻译的提示，点击“仍要打开”（Open Anyway），然后确认“打开”。
6. 如果 Finder 提供按住 Control 点击应用并选择“打开”，也可以使用这条首次启动路径；没有该选项时，请使用上面的“仍要打开”路径。

不要关闭 Gatekeeper，也不要移除隔离属性。当前版本不声明支持 Intel Mac 或 Universal 2。

完整的信任边界和可选包体检查请参阅[分发说明](docs/distribution.md)，版本变化见[更新日志](CHANGELOG.zh-CN.md)。

## 第一次使用

首次引导包含四项设置：

1. **开始前说明。** 了解应用何时读取所选文字，以及文字会发送到哪里。
2. **本机 Ollama。** 检测已经运行的 Ollama 服务并选择一个已安装模型，也可以手动填写已安装的模型名称。
3. **全局快捷键。** 默认为 `⌥⇧D`。如果发生冲突，应用会提供 `⌥⇧F`、`⌥⇧G` 或 `⌥⇧T`。
4. **辅助功能权限。** 只有需要读取其他应用的所选文本时才需要授予。也可以跳过，直接使用手动输入。

轻译不会代替用户安装 Ollama，也不会自动下载模型。基础的本机配置方式如下：

```bash
brew install ollama
ollama serve
ollama pull <model>
```

保持 `ollama serve` 运行，然后回到首次引导或“设置 → 模型”，检测服务并选择已经安装的模型。

## 使用方法

### 翻译所选文本

1. 在受支持的应用中选中文字。
2. 按下 `⌥⇧D`，或在菜单栏菜单中选择“翻译所选文本”。
3. 结果面板会逐步显示译文，并标示源语言、目标语言，以及服务位于本机、局域网还是云端。
4. 可以在面板中复制、重试、更换提示词、固定结果或关闭面板。

选区读取依赖来源应用对辅助功能的支持。如果快捷键无法读取选区，轻译会打开“手动翻译”或说明下一步该怎么做，不会发送无关文字。

### 手动输入翻译

在没有可用选区时按快捷键即可打开“手动翻译”。输入文本，选择源语言、目标语言、提示词和模型服务，然后按 `⌘Return` 或点击“翻译”。这一方式不需要辅助功能权限。

### 开启自动捕获

自动捕获默认关闭。开启步骤如下：

1. 在“设置 → 选择”中授予辅助功能权限。
2. 在“应用程序”中逐个加入允许自动捕获的来源应用。
3. 开启鼠标选区和/或键盘选区。
4. 在“设置 → 通用”中开启“自动捕获”。
5. 如果使用局域网或云端服务，再到“设置 → 模型”中载入该服务的自动应用列表，并授权需要的应用。

可以从菜单栏菜单暂停或恢复自动捕获，不会改变其他设置。

## 配置方法

### 通用

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| 界面语言 | 英文或简体中文 | 英文 |
| 目标语言 | 自动、英文或简体中文 | 自动 |
| 快捷键 | 全局所选文本操作 | `⌥⇧D` |
| 登录时启动 | 登录后启动轻译 | 关闭 |
| 默认提示词 | 快捷键和自动捕获使用的预设 | 准确翻译 |
| 默认模型服务 | 手动输入未另选服务时使用 | 首次引导或配置前为空 |
| 自动捕获 | 自动捕获总开关 | 关闭 |

### 选择

| 设置 | 范围或行为 | 默认值 |
| --- | --- | --- |
| 应用程序 | 自动捕获的逐应用允许列表 | 空 |
| 鼠标选区 | 观察允许应用中的鼠标选区事件 | 关闭 |
| 键盘选区 | 观察允许应用中的键盘选区事件 | 关闭 |
| 防抖时间 | `100–2,000 ms`，步进 `50 ms` | `350 ms` |
| 字符上限 | `1–20,000` 个字符 | `2,000` |
| 快捷键剪贴板回退 | 只在用户按下快捷键时使用，可能替换剪贴板内容 | 关闭 |

自动捕获不会使用剪贴板回退。启用该选项后，按下快捷键可能会模拟 `Command-C` 并读取随后产生的纯文本；应用不保证恢复之前的剪贴板内容。

### 模型

每项模型服务配置包含接口类型、地址、模型名称和可选凭据。凭据保存在 macOS 钥匙串中。

- **Ollama 原生接口：** 内置默认配置连接本机 `11434` 端口上的 Ollama。
- **OpenAI 兼容接口：** 填写服务地址和 API 密钥后获取模型列表，再选择需要启用的模型。
- **发现模型：** 输入提供方的 API 地址和凭据，点击“连接并获取模型”；从返回结果中选择模型并启用，即可将该提供方设为默认。
- **超时：** 连接 `1–60 秒`（默认 `5 秒`）、首个 token `5–600 秒`（默认 `120 秒`）、流空闲 `5–120 秒`（默认 `30 秒`）。
- **明确的提供方选择：** 翻译请求只使用已启用的提供方，不会静默回退到其他本地或云端服务。
- **自动应用：** 非本机服务的自动捕获还需要逐服务授权来源应用。

### 提示词

内置预设为只读，但可以复制为自定义预设后修改。自定义模板：

- 必须且只能包含一次 `{text}`；
- 可以使用 `{source_language}` 和 `{target_language}`；
- 不接受未知占位符；
- 如需输入普通花括号，请使用 `{{` 和 `}}`。

自定义预设名称最多 80 个字符，说明和模板各最多 8,000 个字符。自定义预设会加密保存。

### 隐私与历史记录

历史记录默认关闭。启用后只影响之后完成的翻译；再次关闭不会删除已经保存的记录。

| 设置 | 范围或行为 | 默认值 |
| --- | --- | --- |
| 保留时间 | `1–365` 天 | `30 天` |
| 最大记录数 | `1–10,000` 条 | `1,000` 条 |
| 排除应用 | 不保存所选允许应用产生的历史 | 无 |
| 搜索 | 在本机解密并搜索原文和结果 | — |
| 诊断 | 保存前预览只含分类信息的 JSON 报告 | — |
| 重置 | 分阶段删除应用数据、凭据、密钥和运行配置 | — |

完整的数据流、存储规则、日志排除项、诊断字段和重置限制请参阅[隐私说明](PRIVACY.md)。

## 兼容性与当前限制

- 需要 macOS 14 或更高版本。
- 可下载版本只在 Apple 芯片 Mac 上完成验证。
- 所选文本捕获受来源应用、当前控件、辅助功能支持和 Secure Input 状态影响，不声明所有应用都能兼容。
- 当前 Codex 桌面端界面不提供自动辅助功能选区；用户启用“仅快捷键剪贴板回退”后，可以通过快捷键取得选区。
- 预发布版本没有 Developer ID 签名、公证票据、App Store 收据和自动更新，也没有完成 Intel 或 Universal 2 验证。

已测试的应用列表和各触发方式说明见[兼容性文档](docs/compatibility.md)。

## 从源码构建

环境要求：

- macOS 14 或更高版本；
- 完整 Xcode，安装路径为 `/Applications/Xcode.app`；
- 当前项目验证基线为 arm64 macOS 上的 Xcode 26.6 与 Swift 6.3.3。

运行 Swift 包测试并构建未签名的 Debug 应用：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project GlideTranslate.xcodeproj -scheme GlideTranslate \
  -configuration Debug -destination 'platform=macOS' \
  CODE_SIGNING_ALLOWED=NO build
```

构建并启动本地 Debug 应用：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  ./script/build_and_run.sh run
```

更多说明见[构建文档](docs/building.md)和[验证文档](docs/verification.md)。
